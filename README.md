# machine_learning

In this repository I will document my self learning of machine learning. I consider what I have learned about machine learning and deep learning to be insufficient in todays world and therefore this is my attempt at learning this subject on my own.

This repo will contain small projects as well as useful resources I have found to learn this subject.

# The Plan

Here is a schedule over ten weeks generated by an LLM, it will serve as a guideline to keep track of my weekly goals.

## Part 1 (Weeks 1–2): Foundations and the full workflow

- Supervised learning framing: features, labels, loss, train/validation/test split, overfitting vs. underfitting.
- Linear and logistic regression, plus gradient descent. Write gradient descent yourself once; nothing builds intuition faster.
- Tools: Python, NumPy, pandas, scikit-learn, Jupyter.
- Do one end-to-end Kaggle “Getting Started” problem (Titanic or House Prices).

## Part 2 (Weeks 3–4): Classical ML (where most real-world wins still are)

- Decision trees, random forests, gradient boosting (XGBoost/LightGBM), k-NN, k-means, PCA.
- Practical skills that matter more than algorithms: cross-validation, choosing metrics (precision/recall, ROC-AUC), feature engineering, handling missing data, data leakage.

## Part 3 (Weeks 5–7): Deep learning

- Neural nets, backpropagation, optimizers, regularization, CNNs, embeddings, transformers at a conceptual level.
- Pick PyTorch and build a training loop by hand before using higher-level wrappers.
- Fine-tune a pretrained model (image or text). This is how most practical deep learning is done today.

## Part 4 (Weeks 8–10): A real project

- Choose a problem you care about, ideally from your own work. Take it through every stage: messy data, baseline, iterations, error analysis, and a short write-up of what worked and why.
- The project is where it all consolidates. Don’t skip it for more courses.
